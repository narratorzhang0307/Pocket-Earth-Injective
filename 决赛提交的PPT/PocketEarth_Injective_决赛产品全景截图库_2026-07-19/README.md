# Pocket Earth on Injective 决赛产品全景截图库

本目录只收录 `/Users/zhangcheng/Desktop/Pocket-Earth-Injective` 当前项目的真实软件、Injective testnet 证据和树莓派终端画面，用于决赛 PPT、演示视频与答辩材料。

## 使用纪律

- 禁止混入“上街去”“Carry the Cosmos”、GMI 或其他项目的截图与文案。
- PPT 内同一张截图只使用一次；相邻页面也避免使用构图过近的界面。
- 手机模型统一比例；截图贴满屏幕开口，手机边框与截图之间不留白。
- 链上证据只使用 Injective testnet 页面，并在成稿中裁去浏览器页脚等无关信息。
- 树莓派真机照片与端侧 UI 稿分开标注，不能把模拟渲染描述成现场实拍。

## 分类

1. `01_私人空间`：私人地图、地点照片与本地记忆。
2. `02_公共地球`：Mapbox 公共知识地图与新闻便签。
3. `03_公共知识`：八领域知识卡、新闻展开、每日版次与 Merkle 证明。
4. `04_Frost身份卡`：Frost #43–47 五张身份卡。
5. `05_Agent网络`：公共/私人 Agent、信号台、六步核验、代理社交与夜间报告。
6. `06_口袋播客`：播客模式与文字阅读模式。
7. `07_地球答案`：待揭晓、今日行动与往日回看。
8. `08_Injective证据`：身份、门牌、握手和每日知识版次的真实 Blockscout 页面。
9. `09_硬件终端`：Whisplay 端侧 UI 与树莓派真机照片。
