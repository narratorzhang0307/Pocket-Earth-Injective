# Frost Identity Concepts

This directory keeps the original candidate artwork for comparison. The source
sheet remains untouched; derived trial crops are referenced separately from
`public/frost-identities/`.

## Codex A — 2026-07-18

- File: `codex-a-frost-collection-2026-07-18.png`
- Status: candidate concept sheet; preserved as the source for a reversible UI trial
- Literary invariants: silver-blue square machine, arctic observer, constructed
  eyes and senses, quiet transition from measurement toward human feeling
- Collection rule: one recognizable FROST silhouette with memory-derived
  variations; no rarity tiers, card packs, prices, or speculative traits
- Five directions: core Frost, literature, noir cinema, jazz night, aurora

The visual treatment is intentionally separate from the on-chain claim. A
portrait can express identity, while the verifiable layer remains the agent ID,
metadata/hash, version history, and service records on Injective.
